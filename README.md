# IITJ-Sem2-AI-DS

This repository contains assignment notebooks and class material for Semester 2 AI & Data Science at IIT Jodhpur.

## 📚 Topics

- Foundations of AI
- Numerical Optimization
- Pattern Recognition Principles
- Visualization and Storytelling with Data

## 🧪 Notebooks
Each folder contains:
- Explanation notebooks
- Assignments
- Graphs + figures

## 🚀 How to Run

1. Clone the repo
2. Install dependencies:
   - networkx
   - matplotlib
   - numpy
   - pandas
   - scikit-learn
   - jupyter
3. Open notebooks in Jupyter/VS Code/Colab

> All plots and outputs are already rendered in the notebooks.
